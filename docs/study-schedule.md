# 学习与项目推进计划

这份计划不是打卡表，而是一个长期推进 `t-cex-trade` 和外企工作英语的弹性节奏。目标是在不牺牲身体和生活质量的前提下，把 Java 后端、CEX 交易系统、AI Agent 和英语能力做实。长期理想方向是争取成都或远程的高质量岗位，外企 WLB 是优先目标。

## 1. 总原则

- 健身优先级固定：每天尽量保留 30 分钟。
- 学习不追求每天都有产出，追求每周不断线。
- 工作日以 Java 基本盘和工作英语为主，周末或精力好的晚上再编码。
- 每周只设 1 个技术主目标和 1 个英语主目标。
- 英语不是微习惯，而是外企求职的并列主线；具体训练参考 `docs/work-english-plan.md`。
- 状态差时允许降级，不用补偿式熬夜。
- 具体学习方法参考 `docs/learning-method.md`，每个知识点都要尽量做到可讲、可用、可复盘。

## 2. 每周弹性目标

默认一周只要求完成下面几件事：

1. 健身 4-7 次，每次约 30 分钟。
2. 项目或学习推进 3-5 次，每次 30-120 分钟。
3. 英语训练 5 次左右，每次 30-90 分钟，至少一半时间用于听说。
4. 周日做一次 20-40 分钟复盘，决定下周内容。

理想周：

- 编码 2-3 次。
- 轻学习 2-3 次。
- 英语 5 次，包含 1 次 mock interview。
- 周日复盘 1 次。

普通周：

- 编码 1-2 次。
- 轻学习 1-2 次。
- 英语 3-4 次，至少 2 次开口录音。
- 周日简单复盘。

低能量周：

- 只保留健身、睡眠、一次英文输入和一次 20 分钟复盘。
- 不要求编码。

## 3. 工作日建议

### 周一、周二、周四

这几天下班晚，不安排硬性编码。公司时间优先拆成：Java 基本盘约 3 小时，工作英语约 3 小时。可以从下面任选：

- 看 20-30 分钟技术文档。
- 整理 3-5 条学习笔记。
- 复盘一个问题，例如 MySQL 锁、Kafka 幂等、Redis 缓存一致性。
- 听 10-20 分钟英文技术内容，允许只抓关键词。
- 用英文写 3-5 句项目进展或技术总结，并开口复述。
- 录一次 5-10 分钟英文回答，例如自我介绍、项目介绍、离职原因。
- 什么都不学，只健身和休息。

### 周三、周五

这两天下班较早，可以作为弹性编码窗口。精力够时做 60-120 分钟，不够时只做 20 分钟整理。

可选任务：

- 实现一个小接口。
- 写一个测试。
- 修改一个 OpenSpec task。
- 整理一个模块设计。
- 只列出下次编码要做的 3 个步骤。

## 4. 周末建议

周末不强制两天都学习。优先选择一个主力时间块。

### 可选模式

轻量模式：

- 周六或周日任选 1-2 小时。
- 适合疲劳、社交、家事较多的周。

标准模式：

- 周六 2-3 小时编码。
- 周日 30-60 分钟复盘。

强化模式：

- 周六 3-5 小时编码。
- 周日 1-2 小时测试、文档或面试表达。
- 只在状态好且没有明显疲劳时使用。

## 5. 周日滚动计划与周目标

每周日必须产出下周周目标。目标不用大，但要明确到“本周结束时能判断是否完成”。

周计划存放在 `docs/weekly-plans/`，每周一个文件，命名格式建议为 `YYYY-MM-DD-week-XX.md`。

先回答 6 个问题：

1. 这周有没有不断线？
2. 哪个点最卡？
3. 下周精力大概如何？
4. 下周主目标是什么？
5. 哪些事情明确不做？
6. 英语有没有保持接触？

然后制定 3 层周目标：

- 主目标：本周最重要的一件事，优先保证完成。
- 最低目标：如果本周很累，至少完成什么，避免完全断线。
- 弹性目标：状态好时再做，不做也不补债。

## 6. 工作英语与外企 WLB 目标

英语目标不是短期冲高分，而是逐步具备外企、远程和英文文档环境下的工作能力。它是外企机会的门槛，不是支线。

### 训练重点

- 读：保持英文官方文档阅读能力，例如 Spring、Kafka、OpenAI、LangChain。
- 写：能写项目说明、技术方案、PR 描述和异步沟通。
- 听：先适应技术英语关键词、会议节奏和常见表达。
- 说：准备固定项目介绍和面试回答，不追求一开始自由流利。

### 每周训练

每周尽量完成：

- 3-5 次英文听力输入，每次 10-20 分钟。
- 3-5 次开口复述或录音，每次 5-15 分钟。
- 1 次 20-30 分钟 mock interview。
- 1 段英文项目介绍或技术说明。
- 5-10 个和目标 JD / 项目相关的英文表达。

### 外企求职准备

后期逐步沉淀：

- 英文版自我介绍。
- 英文版项目介绍：`t-cex-trade`、AI Agent 模块、系统设计取舍。
- 英文 PR 和设计文档表达模板。
- 常见外企行为面试回答：冲突、owner 意识、故障复盘、协作方式。
- 远程协作习惯：异步沟通、清晰状态更新、文档优先。

## 7. 阶段路线

阶段路线保持不变，但时间可以弹性调整。

1. 资产模块：用户资产、模拟充值、冻结、解冻、资金流水。
2. 订单模块：限价下单、撤单、订单状态机。
3. 撮合与清算：订单簿、价格时间优先、成交记录、清算幂等。
4. 事件与补偿：Kafka、outbox、消费幂等、对账补偿。
5. 求职增强：Redis、可观测性、压测、AI Agent 辅助模块、面试讲稿。

## 8. 健身与恢复

健身是计划的一部分，不是学习的竞争项。

- 晚下班日优先健身和睡眠。
- 状态差时减少学习，不取消恢复。
- 连续两天疲劳时，本周切到低能量周。
- 不用周末报复性补进度。
- 能长期做下去，比某一周做很多更重要。
