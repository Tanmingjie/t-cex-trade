# 第二周计划：2026-08-31 至 2026-09-06

## 本周定位

本周从“离职冲刺”调整为“在职学习 + 下班项目”的节奏。重点不是高强度推进，而是建立稳定、可持续、可复盘的学习系统。

外企岗位普遍要求英语流利，因此本周把英语从“微习惯”升级为“并列主线”。当前目标不是达到完美流利，而是开始训练外企面试可用的听说表达。

## 时间分工

### 公司时间

- 主线 1：Java 后端基本盘。
- 主线 2：英语工作能力。
- 时间建议：Java 约 3 小时，英语约 3 小时。
- 适合做：阅读、理解、笔记、英文表达、面试问答整理、项目设计草图。
- 不做：公司资料复用、公司代码复用、敏感信息上传、重型联调、长时间构建。

### 下班与周末

- 主线：`t-cex-trade` 项目实践。
- 适合做：编码、测试、本地运行、GitHub 提交、项目英文介绍。
- 晚下班日降低预期，优先健身和睡眠。

## 本周主目标

- 用 Redis 和 Kafka 作为切入点，建立 Java 后端基本盘的第一层理解。
- 准备并开口练习 3 段外企面试英文表达：自我介绍、离职原因、项目介绍。
- 完成 1 次 20-30 分钟英文 mock interview 或录音复盘。
- 周末把本周学习内容映射到 `t-cex-trade` 的下一步项目设计。

## 每天安排

### 周一

- Java：整理 Redis 常见使用场景：缓存、分布式锁、限流、幂等。
- 英语：写英文自我介绍 v1，并录音 1 次。
- 输出：一页 Redis 场景笔记 + self introduction 初稿 + 录音自查。

### 周二

- Java：整理 Kafka 基础概念：topic、partition、consumer group、offset。
- 英语：写 `Why do you want to leave your current job?` 初稿，并读熟。
- 输出：一页 Kafka 概念笔记 + 离职原因英文回答 + 5 个可复用表达。

### 周三

- Java：学习 Kafka 在订单系统中的作用：异步、削峰、事件驱动。
- 英语：阅读 1 个 Maersk 或 EPAM JD，摘出 10 个高频表达，并口头复述岗位要求。
- 输出：订单事件流草图 + JD 表达清单 + 2 分钟口头复述。

### 周四

- Java：学习 Redis 在交易/订单系统中的作用：热点数据、幂等、限流。
- 英语：写 `Tell me about your recent project` 初稿，并录音 1 次。
- 输出：Redis 项目应用笔记 + 项目介绍英文稿 + 录音自查。

### 周五

- Java：复盘 Redis/Kafka，分别回答“为什么用、怎么用、有什么坑”。
- 英语：做一次 20-30 分钟英文 mock interview，可以自问自答并录音。
- 输出：Redis/Kafka 面试问答各 5 个 + mock interview 复盘。

### 周六

- 项目：梳理 `t-cex-trade` 第一条纵向链路：下单、资产冻结、事件发布、状态查询。
- 项目：决定哪些内容需要 OpenSpec 先行设计。
- 输出：下一步项目任务清单。

### 周日

- 复盘：检查本周学习是否不断线。
- 计划：制定下一周周目标。
- 输出：周复盘 + 第三周计划草稿。

## 每天固定动作

- 健身 30 分钟。
- 英语听说训练 20-30 分钟，最低也要开口 5 分钟。
- 当日复盘 10 分钟：今天学了什么，明天接什么。

## 本周不做

- 不系统啃完整 Redis/Kafka 课程。
- 不追求一次性补完 JVM、MySQL、Spring 全部知识。
- 不只刷英文阅读，必须加入听说和录音。
- 不做重型 Docker/Kafka/MySQL 联调。
- 不因为计划没完成而补偿式熬夜。
